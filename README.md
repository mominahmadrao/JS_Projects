# JS_Projects

A collection of practical JavaScript projects and exercises to improve coding skills, explore DOM manipulation, and understand JavaScript concepts in real-world scenarios.

## Projects 📝

### 1. TODO List - Local Storage

A simple TODO list application that allows users to **add, delete, and persist tasks** using local storage.  
Live Demo: [🌐 https://01-todo-local-storage-inky.vercel.app/](https://01-todo-local-storage-inky.vercel.app/)

### 2. Weather App

A simple and responsive Weather Application that allows users to check real-time weather conditions for any city. It fetches live data from a weather API and displays temperature, weather status, humidity, and more in a clean UI.

Backend to handle api key is on render

Live Demo: [🌐 https://weatherapp-pi-ecru.vercel.app/](https://weatherapp-pi-ecru.vercel.app/)

### 3. Ecommerce App

E-commerce app that add products to carts and give you the total amount

Live Demo: [🌐 https://ecommerceapp-tau-two.vercel.app/](https://ecommerceapp-tau-two.vercel.app/)

### 4. Expense Tracker App

Expense Tracking app to track your day to day expenses

Live Demo: [🌐 https://expensetracker-lyart-zeta.vercel.app/](https://expensetracker-lyart-zeta.vercel.app/)

### 5. Quiz App

A simple interactive Quiz App built with HTML, CSS, and JavaScript.
Users can answer multiple-choice questions and receive instant feedback on their selections.
The app highlights correct and incorrect answers and keeps track of the user's score.
At the end of the quiz, the final score is displayed with an option to restart and try again.

Live Demo: [🌐 https://quizapp-pearl-beta.vercel.app/](https://quizapp-pearl-beta.vercel.app/)
